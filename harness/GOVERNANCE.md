# Governance

## Purpose and authority

This repository owns the composition-contract proposal and its future public interfaces. Jan owns project direction and publication decisions. Intended reviewers are not automatically approvers or maintainers. AOUSD affiliation, adoption and endorsement must never be inferred from an invitation to discuss.

Keep three evidence classes distinct: OpenUSD mechanics supported by precise upstream sources; published workflow examples with their own scope; and project conventions still under evaluation. An accepted project rule is not a universal USD requirement. The current contract is a working baseline for discussion.

## Ownership and dependencies

CompositionContracts.md is the single prose owner of the CC rules. Tooling requirements define planned execution obligations. Future machine-readable profiles must identify their contract revision and rule IDs; neither implementation nor a successful example silently redefines the contract.

Sibling projects provide routed references, not inherited governance or permission to edit. The private pipeline-nodes project is optional and unassessed. No private implementation content is included here.

## Change and publication boundaries

Preserve source provenance and earlier evidence. Explain changes to semantics, distinguish behavior-preserving repair from intended behavior change, and record unresolved ownership. Do not infer approval from elapsed time or a successful command.

Use local, reviewable changes within the requested scope. Remote repository creation, invitations, messages, publication, commits and pushes require a corresponding request. License selection and contribution terms remain open before distribution. Do not invent a license or imply upstream rights transfer.

## Harness basis

The [AI Harness guide](https://haluszka.com/ai-harness-quickstart/guide/) informed the separation of selected context, procedure, boundaries, evaluation and durable state. Our working entrypoint is AGENTS.md; governance, workflow and state have separate owners to keep resumption practical. This is a small project harness, not a deployed agent service.
