# Contributing to the proposal

Start with README.md and DISCUSSION.md. Propose one bounded concern at a time: affected CC IDs, use case, current behavior, proposed behavior, alternatives, source references and a minimal example or expected result. Label untested claims and distinguish personal agreement from group acceptance.

Keep mechanics, conventions and implementation evidence separate. Preserve rule IDs and record substantive decisions. Do not include confidential models, private repository content or third-party assets without appropriate permission.

Licensing, contribution terms and remote collaboration arrangements have not yet been selected. This bootstrap creates no automatic rights grant or group affiliation. Sharing and contribution arrangements will be established by the maintainer before external distribution.
