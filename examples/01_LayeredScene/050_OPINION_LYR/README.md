# Saved scene opinions

Each scene owns `OpinLYR_Scene<Name>.usda` in this folder. Save scene selections
and working overrides there; no separate variant-selection layer is required.
An optional contributor uses `.name.usda`, with no identifier by default.
`ReviewLyr_SceneMaskedSize.usda` and `ReviewLyr_SceneMaskedSelection.usda` are
intentional conflict demonstrations used only by their corresponding roots.
