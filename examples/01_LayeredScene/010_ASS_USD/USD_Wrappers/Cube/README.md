# Cube reusable package

Open AssetROOT_Cube.usda. Opinion is the default authoring layer when opened directly in compatible Kit; other layers are protected. 020_BASE_LYR contains this package's geometry, transforms and controls. 050_REVIEW_LYR contains package-owned experiments; saving them affects every consumer. When used inside a scene, author scene experiments in the scene Opinion instead. Other class directories are reserved, not empty USD layers. A building or workcell follows the same AssetROOT convention when reused in a larger scene.
