# Portable setup

Copy this entire folder into the intended project location. Keep the BAT, PS1 and ZIP together. Double-click Create_Composition_Project.bat. It expands the preset beside itself. To choose another destination, run `Create_Composition_Project.ps1 -Destination "E:\Projects\MyWorkcell"`.

Windows PowerShell is required; Python, network access and administrator rights are not. Existing destination files stop setup before extraction; never rerun over edited work. After extraction, read START_HERE.md and launch Open_In_Kit.ps1. The setup does not install Omniverse, physics solvers or runtime connectors.
